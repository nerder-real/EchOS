# v1.3.0

授权体系 + TUN 模式同期上线的大版本。

- **客户端授权**：设备码注册激活、一机一码；吊销 / 封禁 / 换码即时生效，恢复后自动续跑
- **TUN 模式**：IPv4 / IPv6 全栈接管，浏览器、终端与任意 App 统一走隧道；系统代理自动让位，退出 / 关闭后自动恢复
- **边缘优选**：按真实链路吞吐持续探测并择优，自动剔除失效线路并保留备用
- **连接预热与保活**：常用连接提前建立，空闲隧道不被中途回收，播放拖动不再等数秒
- **系统代理巡逻**：代理设置被其他软件改动时自动纠正；TUN 模式下同样生效
- **对齐 Windows 端**：停止中双按钮禁用、端口就绪即接管、自检失败自动复测、托盘菜单口径统一
- **配置管理**：整份配置本地 / WebDAV 备份还原；服务器可分享、导出、导入
- **界面**：启动页 / 激活页 / 主页面同窗三态；单实例运行，重复启动唤醒已有窗口

macOS 13.0 以上，Intel 与 Apple 芯片通用。无 Apple 开发者签名，首次打开请右键 → 打开。
